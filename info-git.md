Git — распределённая система управления версиями. Позволяет отслеживать изменения в файлах и работать над проектом в команде.

GitHub — веб-сервис для хостинга IT-проектов и их совместной разработки. Основан на системе Git.

- `git clone` — клонировать репозиторий
- `git add` — добавить файлы в индекс
- `git commit` — зафиксировать изменения
- `git push` — отправить изменения на сервер
- `git pull` — получить изменения с сервера
